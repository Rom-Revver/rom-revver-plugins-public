# ROM Inspector

Calibration properties and the full table list for the open ROM, in one panel.

## What this plugin does

Shows the open ROM's calibration and vehicle properties (the same data behind
the ⓘ properties panel), then lists every table in the loaded definition below
it — a quick way to see how many tables a definition covers, or to confirm a
ROM matched the definition you expected.

## Why install it

- A fast overview panel without opening the full table tree.
- Handy when comparing two ROMs' definitions side by side.

## Capabilities

None — display-only. It never changes your ROM.
