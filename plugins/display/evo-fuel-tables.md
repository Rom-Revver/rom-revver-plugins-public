# Fuel Tables

Every Fuel-category table in the loaded definition, for any Evo platform.

## What this plugin does

Lists every table the loaded definition files under its **Fuel** category —
click one in the tree to open it. Categories come from the definition itself,
so this works on any platform whose defs categorise fuel tables the same way
(Evo ECUFlash sets do).

## Why install it

- A quick jumping-off point into fuel tuning without filtering the full tree
  by hand every session.

## Capabilities

None — display-only. It never changes your ROM.
