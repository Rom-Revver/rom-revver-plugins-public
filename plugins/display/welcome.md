# Welcome

An introduction to ROM Revver plugins, and a tour of what a panel can show.

## What this plugin does

Opens a single panel explaining that plugins are **declarative** — a small JSON
file the app renders, never code that runs. It's a good first install to confirm
plugins are working and to see the block types available to any panel: headings,
rich `text`, your ROM's properties, and table lists.

## Why install it

- A safe, read-only starting point before trying a config-mod or firmware-patch plugin.
- Points you at the other example plugins to explore next.

## Capabilities

None — display-only. It never changes your ROM.
